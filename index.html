Acceptable Use Policy

Käyttämällä Agentic Idea Discovery -sovellusta sitoudut seuraaviin ehtoihin:

  • Älä yritä väärinkäyttää järjestelmää — älä syötä haitallisia komentoja, koodia tai prompt injection -yrityksiä.
  • Älä yritä murtautua — tietoturvan testaaminen ja datan manipulointi on kiellettyä.
  • Kunnioita muita käyttäjiä — älä esiinny toisena henkilönä tai lähetä loukkaavaa sisältöä.
  • Käytä resursseja vastuullisesti — älä kuormita järjestelmää tarkoituksellisesti.
  • Ideat ovat julkisia — kaikki syöttämäsi ideat näkyvät muille. Älä jaa luottamuksellista tietoa.

Rikkomukset johtavat käyttäjätilin estämiseen.

🚀 Deploy Pipeline
Agentit luovat sovellukset GitLab-repoon alihakemistoihin. Julkaisu tapahtuu automaattisesti GitLab Pagesin kautta kun koodi pushataan main-haaraan.
🦊 GitLab Repo 🌐 GitLab Pages
git push → GitLab CI → Pages julkaisu → rapid-agent-prototypes-af869c.gitlab-siili.io/{hakemisto}/
🤖 Worker Agent MD Files
Worker-agentit toimivat omissa hakemistoissaan (esim. Site_Tour/Helsinki_xxx/) ja lukevat ohjetiedostot polulta ../Worker_agent_MD_Files/.
📁 Rakenne
Site_Tour/
├── Worker_agent_MD_Files/
│   ├── _agent.js
│   ├── AGENT_SAFETY.md
│   ├── AGENT_IMPLEMENT.md
│   ├── AGENT_FETCH_IDEAS.md
│   └── AGENT_STATUS.md
├── Helsinki_20260429_xxx/  ← worker 1
└── Helsinki_20260430_yyy/  ← worker 2
📄 Tiedostot
_agent.js — CLI-työkalu (status, reply, fetch)
AGENT_SAFETY.md — Turvasäännöt (pakollinen)
AGENT_IMPLEMENT.md — Toteutusprosessi
AGENT_FETCH_IDEAS.md — Ideoiden hakuohje
AGENT_STATUS.md — Statuskirjoitusohje
